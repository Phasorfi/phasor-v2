# Roadmap

### Phase 1 — Testnet (February 2026)

**Status: Going live imminently**

The foundation. Deploy core infrastructure on Monad testnet, validate all contracts, and begin building the community.

* ✅ Core AMM deployed (volatile + stable pools)
* ✅ Router with multi-hop swap routing
* ✅ vePHSR voting escrow and gauge system
* ✅ PHSR emissions with weekly epoch cycle
* ✅ Rebase distribution for vePHSR holders
* ✅ Time multiplier on gauge staking (1x → 3x over 90 days)
* ✅ Ve-gated launchpad with automatic liquidity injection
* ✅ Frontend: swap, liquidity, staking, governance, launchpad, portfolio
* ✅ Documentation and user guides
* 🔜 Community testing and bug reporting
* 🔜 Testnet incentive program

### Phase 2 — Mainnet Launch (March–April 2026)

Go live on Monad mainnet. Bootstrap initial liquidity, onboard launch partners, and activate the full ve(3,3) flywheel.

* Security audits (internal + external) before mainnet deployment
* Mainnet deployment of all core contracts
* Initial liquidity bootstrap across key pairs (WMON, USDC, WETH, WBTC)
* First launchpad sales live
* Early Supporters round and public token distribution (TGE)
* vePHSR locking and first governance votes
* Bribe system activation
* Security monitoring and incident response infrastructure
* Block explorer verification for all contracts

### Phase 3 — Growth & Ecosystem

Scale the protocol. Attract projects, deepen liquidity, and expand the product suite.

* Partnership program for projects launching on Monad
* Bribe marketplace with analytics (bribe efficiency, ROI tracking)
* Enhanced analytics dashboard (TVL, volume, fee generation, top pools)
* Gauge performance metrics and voting recommendations
* Zap functionality (single-sided liquidity provision)
* Multi-token bribe support and bribe aggregation
* Protocol revenue dashboard for vePHSR holders
* Mobile-optimized experience
* Community grants program

### Phase 4 — Advanced AMM

Introduce next-generation AMM mechanics to improve capital efficiency and attract sophisticated LPs.

* Concentrated liquidity pools (allowing LPs to target specific price ranges)
* Custom fee tiers per pool
* Advanced order types (limit orders, TWAP)
* LP position management tools (auto-rebalance, range alerts)
* Cross-pool routing optimization
* Oracle infrastructure for on-chain price feeds

### Phase 5 — Decentralization & DAO

Transition protocol governance fully to the community.

* On-chain governance proposals and voting (beyond gauge votes)
* Treasury management via DAO
* Protocol parameter changes governed by vePHSR holders
* Timelock on all governance actions
* Progressive removal of team admin privileges
* Community-elected multisig for emergency actions
* Open grant framework for ecosystem contributors

### Beyond

The long-term vision is for Phasor to be the default liquidity layer on Monad — where every token has deep liquidity, every project can launch fairly, and every participant is rewarded for contributing to the ecosystem.

Future explorations may include:

* Cross-chain liquidity (bridged pools or messaging)
* Lending and borrowing integration
* Perpetual futures or structured products
* Programmable liquidity strategies (vaults, auto-compounding)
* SDK and API for third-party integrations
